1. Create the clauses in *Invoicing > Configuration > Contracts > Contract Clauses*.
2. Create the document templates (type, body, clauses).
3. List them on a contract template (*Documents*), or directly on a contract
   (*Documents* tab).
4. Press *Generate documents* on the contract, review and print each one.
5. To change an issued document, open it and press *New addendum*.
